这座城还派不出活

第一步只有一件事：告诉它去问哪个模型。这台机器上的密钥不会离开这台机器。

没有模型回答 main 这个用途。 接上之后，你写一句话，它就能派出去做。

读的是这台机器上已注册的 endpoint 与它们各自答应的用途。

还没有地方放活

楼（一条业务线，磁盘上就是一个文件夹）是活落脚的地方；一次派活会在楼里开一间房。

这座城一栋楼都没有。 建一栋，比如 lab；之后每一件活都住在它下面的一间房里，房间名就是你给这件活取的名字。

读的是城根目录下已有的楼。
