# 上手——从空目录到第一个跑完的 Run

> **给第一次安装它的人。** 这一份把整条路走一遍，一步不跳，走到「模型做完一件活并写下一个文件」为止。
>
> 它不解释词汇（[`glossary.md`](glossary.md)），不讲日常操作（[`operating.md`](operating.md)），也不讲设计（[`../ARCHITECTURE.md`](../ARCHITECTURE.md)）。英文版是 [`getting-started.md`](getting-started.md)。

## 你需要什么

一个桌面浏览器，和 `sprawling` 这一个二进制。别的都不需要——不装 npm，不装 node，不装语言运行时，不装数据库。

还需要一个能调用的模型：一个说 OpenAI 或 Anthropic 兼容格式的 provider 的 API key，或者一个说这两种格式之一的本地服务。

想自己构建而不是拿现成的二进制，看 [`CONTRIBUTING.md`](CONTRIBUTING.md)。前端先构建、再被嵌进二进制，所以只跑一次 `cargo build` 得到的二进制里装的是昨天的页面。

## 1 建一座城

```bash
sprawling init ~/cities/first
```

一座城就是一个目录，一切都在它里面。这一步写下创世记录，城名也存在那里——浏览器从记录里读城名，不从目录名读。

## 2 起控制面

```bash
sprawling serve ~/cities/first
```

它绑 `127.0.0.1:8787` 并打印自己听在哪里。打开那个地址。

要让同一网络里的另一台机器连进来，先给一个要绑的地址并设配对令牌：

```bash
SPRAWLING_PAIRING_TOKEN=<你自己定的令牌> sprawling serve ~/cities/first 0.0.0.0:8787
```

绑非回环地址而没有令牌，它**拒绝启动**。这是绑定时刻的判定，不是请求时刻的：一座起得来却谁都拒的城看上去像网络故障，而一座起得来且谁都收的城更糟。

## 3 给它一个 provider

在左栏 *setup* 下打开 **settings**。

填你要叫它什么、base URL、兼容格式。URL 的规矩就写在你输入的地方：`https` 到哪都行，`http` 只能到本机。key 最后填。

**key 不会成为一条命令的一部分。** 它走自己的路进操作系统的凭证服务，回到页面上的只有一个 `secret:realm/name` 形式的引用。此后出现在配置、事件、日志里的都是这个引用，明文只在凭证库里。输入框在发出的一刻就被清空。

按 **attach**。城会调用 provider 的模型列表，看看它提供什么。一个答不出可用内容的 provider 在这里就说清楚，而不是等到第一次派活。

然后按标签选模型。开头有两个标签要紧：

- `main`——负责思考的模型。
- `digest`——替 `main` 读长文档的模型。

两个可以是同一个模型。上下文窗口和输出上限不用你填：那是模型的事实，城从刚取回的目录里读。

### 或者用订阅登录

如果你的 provider 是按订阅付费而不是按 token 付费，用同一页上的 **sign in with a subscription**。它发起登录、给你一个要打开的 URL、等你把 provider 显示的码贴回来。贴回来之后，令牌连同它的端点一起落进凭证服务，并在过期之前续期——不是等一次调用被拒之后才续。

今天这张情报表里只有 Anthropic 那一行是全的。某一行是空的 provider 会拒绝发起，而不是把你送进一个空页面。

## 4 盖一栋楼

去 **city**。图下面的表单要一个名字和一个模板。

- `minimal`——一栋普通的楼。
- `confidential`——数据进得来出不去：模型池是本地的，写别的楼恒被拒。

楼名是一个顶层地址：`lab`，不是 `lab/room1`。房间随后再有，它们就是子目录。

新楼立刻拿到自己的几份文档——楼根下的 `Roadmap.md`、`Memo.md`、`Handoff.md` 是这栋楼的记忆，Agent 既读也写；`.sprawling/BUILDING.md` 是它的规则，你写、在这栋楼里干活的 Agent 只读得到。你可以在浏览器里选中这栋楼、按 **read it** 来读；同样这几个文件就在盘上，你更想用编辑器也行。

## 5 派一件活

每一页底部那条是控制面。它问四件事：

| 字段 | 它要什么 |
|---|---|
| address | 哪个房间，写成 `building/room`——或者就写楼名 |
| what to produce | 一行话 |
| what counts as done | 你将据以判定的条件 |
| mode | 它该怎么干活；`plan` 是常用的那个 |

**它不问预算。** 一件活跑之前没人说得出它值多少钱，订阅更是没有单价；花了多少事后从记录里报出来，在成本页上。

按 **send it**。城写下 `run_started`，组装冻结 prefix，调用模型；从这一刻起，每一次工具调用和每一个结果都是账本里的一行。

## 6 看着它，读它做了什么

**live** 跟着会话走。你要选看哪一个 Run——同时有两个在跑时「最新那个」是抛硬币，所以页面让你选，而不是替你选。窗口是有界的，并且会说出有多少行掉出了窗口；那些行仍在账本里。

**ledger** 是整条事件流，可过滤、可翻页。它只显示这一页连上之后到达的事件，并且明说这一点；城的账本总长在城市页顶部的体征条上。

**cost** 是它花了多少，切成五个维度。provider 没报价的那些，页面报 token 数并说明为什么没有金额，而不是打印 `$0.00`。

Run 跑完，它写的文件就在那栋楼里。开楼页读，或者去盘上看——是同样的字节。

## 7 停下，再开始

在服务端按 `Ctrl-C`，或者在页面上按 **stop the city**——后者会让每一个 Run 都读作已停，并被记录下来。

重启之后：

```bash
sprawling resume ~/cities/first
```

这一步验链、关掉那些「进程死时结果已丢失」的工具调用、报出谁在等人。一座在调用途中被杀掉的城，回来时说的是它不知道什么，而不是假装知道。

## 出了问题

| 你看到 | 它是什么意思 |
|---|---|
| 页面说 schema 不匹配 | 二进制和浏览器里的页面不是同一个版本。刷新。 |
| attach 之后模型列表是空的 | provider 答了，但答的内容这个构建读不出来。拒绝信息里写着它收到了什么。 |
| 一个 Run 停下来要东西 | 有件事需要人。它在 **approvals** 页上，按簇分组，一个回答覆盖一个问题。 |
| 一个 Run 冻住了 | 预算、看门狗，或者某个上限。live 页说是哪一个。 |
| 一个文件不见了 | 去 **recycle bin**。每一行都写着怎么把那个文件取回来。 |

更多这类情况和各自的处置在 [`operating.md`](operating.md)（英文）。
